# 需求变更记录

## v1.0 — 2026-11-08
- 正式建立需求基线与验收编号。
- 本地显式代理端口改为 18585；VPS HTTPS 端口使用 8443。
- 选择本地完整内存缓冲与 MD5、纯 MD5 缓存命中、固定 30 分钟、进程内索引+重启扫描、最多额外 3 次重试、VPS 故障直传回退。
- 不接管 R2 合并流程；记录已接受的故障恢复边界。

后续修改：先由 Issue 描述影响，经过 Owner 确认后同步需求、验收和相关 ADR。

## v1.1 — 2026-11-08
- 新增 RLY-017：Owner 指定 Commit SHA、GitHub Actions 受限 SSH 部署、版本化切换、健康检查和自动回滚。
- 新增 T19，要求部署触发权限、Commit/CI 校验及生产影响边界可验收。

## v1.2 — 2026-11-08
- 将生产部署 SSH 身份收敛为独立无密码系统账号；sudo 仅允许执行固定 Root receiver。
- 修复 CI 检查解析和失败回执丢失，并加强原子切换/回滚写入的持久性。

## v1.3 — 2026-11-08
- Bootstrap 拒绝未锁定的既有部署账号，避免覆盖账户安全状态；拒绝无账号但残留的 Home 目录，避免失败清理误删数据。
- sudoers 将固定 receiver 限定为无额外参数调用；部署锁文件增加 root 所有权、普通文件、私有权限和单硬链接校验。
- 部署备份在切换前执行文件与目录 fsync，回滚删除 current 指针时同步父目录。
- 扩展部署安全测试：重复/绝对归档路径、锁文件和 sudoers 策略。

## v1.4 — 2026-11-08
- 已存在但非当前运行的 release 不再直接拒绝；先检查目录/文件所有权、权限、Python 解释器符号链接及运行时导入，再复用既有版本。
- 支持自动回滚后重试相同 SHA，以及切回已安装的旧 SHA；不覆盖既有 release。


## v1.5 — 2026-11-09
- 根据 Owner 对 R2 Relay 真实网络验收范围的明确决定，T16 不再要求真实网络 4/8/16 并发测试。
- 已有 GitHub Runner 100×10 MiB、内部并发 8 的 MockTransport 结果仅作为历史离线模拟证据，不代表真实公网吞吐，也不要求为此重新跑并发矩阵。
- 真实 Mac→VPS 已有网络观测独立归档于 Issue #17；客户端端到端与 VPS sink 服务端吞吐分开统计。
- 真实 R2 Multipart、VPS→R2、长时间稳定性及故障恢复仍按各自状态标记，不由离线模拟结果推断。


## v1.6 — 2026-11-19
- 新增独立 R2 Download Relay v1 需求基线（Issue #63），不改变现有上传路径。
- 确认 VPS 单 GET、流式生成 16 MiB Part、严格超过 24 MiB 才启用分片；Mac 单文件并发 16、全局并发 32。
- 四个参数全部由 TOML 配置管理；本地完整取回和验证后才向原始客户端返回。
- 新增 mitmproxy 大文件磁盘响应 PoC Gate，未通过前不进入完整下载实现。
- 明确本需求不授权 VPS 部署。


## v1.7 — 2026-11-19
- 将 R2 Download Relay v1 的需求编号范围明确为 RLY-020～RLY-039。
- 记录 Gate 0：1 GiB Loopback 磁盘响应 PoC 已通过；regular CONNECT 客户端侧使用 HTTP/1.1，RSS 增量实测 0.3 MiB，客户端断开可传递至文件服务。
- 明确 Mac RelayClient → VPS 的 HTTP/2 属于独立链路，须在后续下载全栈测试中单独验收，不将 CONNECT HTTP/1.1 结果误记为 HTTP/2 通过。


## v1.8 — 2026-11-19
- 新增独立的 VPS 下载任务 API、16 MiB 原子 Part writer、manifest、READY 等待式读取、小响应 body API、幂等删除和空闲 TTL 清理。
- VPS 下载配置改为 TOML；默认关闭，启用前必须按实际磁盘容量填写缓存预算、剩余空间、活动/保留任务及等待者上限。
- 明确 VPS 重启后旧下载任务不恢复，启动时清理孤儿下载目录，避免恢复不完整对象。
- 修正下载验收矩阵中 RLY 编号映射。


## v1.9 — 2026-11-19
- Stage 1 代码审查加固：原样构造 GET 请求以避免 HTTPX 默认请求头干扰签名；校验签名 Host 与 URL 主机名一致。
- 修复全局等待者计数跨任务并发竞争、Part 失败状态映射和 reader 与 TTL/删除之间的竞态。
- 下载目录增加 Linux 单进程独占锁，关停时先取消 writer、等待 reader 结束再释放锁。
- 限制 URL 与请求头输入规模；manifest 不回显底层异常文本，降低签名 URL 泄露风险。
